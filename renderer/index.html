        A path you can inspect.
        Orivo starts with the element you point to, then follows evidence collected by your development app.
        1. Rendered elementThe exact DOM node you selected.
        2. Frontend sourceThe original file, line, expression, and matching source hash.
        3. API requestThe actual request and the response field used by the element.
        4. Backend executionThe correlated handler and SQL queries that ran.
        5. Data originThe table and column, only when a field adapter captured that relationship.
        Running a query during a request does not prove that a particular field came from it. Partial traces are useful; Orivo does not fill their gaps with guesses.
