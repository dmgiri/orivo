# Orivo 0.1.0 beta

Orivo 0.1.0 beta is a local development tracing tool. It follows captured evidence from a visible UI value through frontend source, requests, backend execution, SQL, and supported database-origin mappings.

> [!CAUTION]
> Development only. Use Orivo only with local development projects. Do not use it with production applications or production data.

## Package notes

- Windows x64 packages include a portable ZIP archive and an unsigned per-user `Setup.exe` installer.
- Linux x64 packages are portable `.tar.gz` archives built for Linux environments.
- Extract the package completely before launching it. No Node.js or npm installation is required.
- This beta has no automatic updates or code signing.

See the repository README for supported tracing paths, coverage limitations, and project setup.
